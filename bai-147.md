### Tên và ngày phóng của vệ tinh được phóng gần đây nhất của mỗi nhà sản xuất là gì?

### Mô tả bảng

**Bảng manufacturers**

```
Mô tả bảng+-----------+-----------+
| Cột       | Kiểu dữ liệu |
+-----------+-----------+
| id        | INT       |
| name      | TEXT      |
+-----------+-----------+
```

**Bảng satellites**

```
Mô tả bảng+------------------+-------------+
| Cột              | Kiểu dữ liệu |
+------------------+-------------+
| id               | INT         |
| manufacturer_id  | INT         |
| name             | TEXT        |
| launch_date      | DATE        |
+------------------+-------------+
```

### Nhiệm vụ

Tìm ra **vệ tinh được phóng gần nhất (có launch_date lớn nhất)** của **mỗi nhà sản xuất**, đồng thời hiển thị:

### Mô tả bảng

-   Tên nhà sản xuất
-   Ngày phóng vệ tinh
-   Theo thứ tự launch_date tăng dần

### Input mẫu

**Bảng manufacturers**

```
Mô tả bảng+----+---------------+
| id | name          |
+----+---------------+
| 1  | SpaceX        |
| 2  | NASA          |
| 3  | Roscosmos     |
+----+---------------+
```

**Bảng satellites**

```
Mô tả bảng+----+------------------+-------------+-------------+
| id | manufacturer_id  | name        | launch_date |
+----+------------------+-------------+-------------+
| 1  | 1                | FalconSat   | 2020-01-10  |
| 2  | 1                | Starlink-5  | 2024-05-22  |
| 3  | 2                | Hubble      | 1990-04-24  |
| 4  | 2                | Artemis-1   | 2022-11-16  |
| 5  | 3                | Luna-25     | 2023-08-11  |
+----+------------------+-------------+-------------+
```

### Output mẫu

```
Mô tả bảng+-------------+-------------+
| name        | launch_date |
+-------------+-------------+
| NASA        | 2022-11-16  |
| Roscosmos   | 2023-08-11  |
| SpaceX      | 2024-05-22  |
+-------------+-------------+
```
