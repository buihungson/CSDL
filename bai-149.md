**Nhiệm vụ**

Xác định các công ty hoạt động ở nhiều hơn 1 quốc gia?

| company_name | country   |

| Amazon    | USA     |

| Amazon    | UK     |

| Alibaba   | China    |

| Alibaba   | Singapore  |

| Netflix   | USA     |

| Netflix   | Canada   |

| Netflix   | Mexico   |

| Baidu    | China    |

+----------------------+---------------+

output mẫu

+----------------------+

| company_name |

+----------------------+

| Amazon    |

| Alibaba   |

| Netflix   |

+----------------------+
